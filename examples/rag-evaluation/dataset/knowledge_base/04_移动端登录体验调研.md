# 星河协作平台移动端登录体验调研

## 调研背景

产品团队在 2026 年第二季度访谈了 28 名移动端用户，重点了解登录入口、账号切换和生物识别确认的使用感受。受访者经常提到“登录”“账号”“验证码”和“会话”等词，但本调研只记录体验反馈，不定义认证系统的令牌有效期或故障处理规则。

## 主要反馈

多数用户希望登录页能够记住最近使用的企业域名。拥有两个企业账号的用户认为账号切换入口太深，常常要先退出当前账号才能找到另一个账号。部分用户把“退出账号”和“关闭应用”理解为同一个动作，因此产品文案需要明确说明二者的区别。

生物识别登录得到较高评价，但用户希望失败后可以直接切换到系统密码或短信验证码。验证码倒计时期间，重新发送按钮应保持禁用，同时展示剩余秒数。错误提示要说明下一步动作，不能只显示“登录失败”。

## 设计建议

登录页保留企业域名和最近账号，敏感凭证仍由系统安全存储管理。账号切换入口放到头像菜单的第一层。发生登录异常时，界面应展示可理解的错误提示和帮助入口。

这些建议需要经过可用性测试后再进入排期。本调研没有规定客户端收到 HTTP 401、403 后应该刷新几次，也没有规定生产版本的发布窗口、回滚阈值或值班响应时间。相关工程规则应以认证故障手册和生产发布手册为准。
